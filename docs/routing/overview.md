# Stage-1 软件路由概览

本实现遵循 **Ideas 2026.10.21** 的阶段边界：它是一个可配置 N 节点的纯软件模拟器，用来验证
网络创建、删除、查询、资源占用、隔离和确定性失败语义。N 是模型参数；真实 Jumperless 的节点
清单与正式节点数仍待确认，代码和文档都不把某个数值声称为官方规格。

“任意两点可按需连通”只表示模型可以为一次请求寻找空闲资源，**不等于**所有可能的多网络组合
都能同时存在。不同 net 不共享节点或 link，避免在模型中形成非预期短接。资源不足时 stage 1
直接返回结构化失败；它不会移动既有 net，也没有 rearrange API。重新安排已有连接属于 stage 2。

本阶段不包含 CH446Q 寄存器控制、PCB netlist、硬件 Clos 拓扑、固件或物理电气可行性声明。
完整图只是明确标注的仿真资源模型，不能据此推断真实硬件能力。

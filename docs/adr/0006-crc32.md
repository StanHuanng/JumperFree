# 0006 zlib 兼容软件 CRC32（D7）

## 状态

已采纳；core 已有 CRC32 工具，JF2 与 C 对等实现后续完成。

## 背景

主机与固件必须对完全相同的事务字节得到相同校验值，F103 硬件 CRC 处理方式不能直接替代 zlib。

## 决定

统一使用 zlib 兼容 CRC32，Python 用标准库 `zlib.crc32(data) & 0xffffffff`，固件用兼容的软件实现，不使用 F103 硬件 CRC 单元。采用 CRC-32/ISO-HDLC：反射多项式 `0xedb88320`，初值与最终异或均为 `0xffffffff`；`123456789` 的结果为 `cbf43926`。JF2 COMMIT 按 seq 顺序对每个操作的 `"<tok>\n"` 字节拼接取 CRC。

## 后果

两端用共享向量验证字节序列与 CRC 一致；CRC 只检错，不提供认证或物理反馈。C 实现尚未完成，未经硬件验证。

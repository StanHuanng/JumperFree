# 0003 CLI 默认 LEASE 0、持续会话用租约、任何故障全断（D2）

## 状态

已采纳用户 D2；供后续 JF2 与固件实现，M1 无租约命令。

## 背景

一次性 CLI 执行完即退出；若默认短租约，会在用户仍使用电路时自动断开。

## 决定

一次性 CLI 默认 `LEASE 0`，保持当前连接；持续会话默认启用租约并发心跳，断连后心跳停止，租约到期进入 SAFE 全断。任何模式下，任何故障均全断。上电、复位、ALLOPEN 同样全断；事务提交强制先断后通，中途故障全断。设备重启后不得静默恢复连接。

## 后果

`LEASE 0` 下被动 UART 无法检测拔线，外部供电时连接可能继续保持，这是明确取舍。租约、RST 与看门狗路径均未经硬件验证，需 M6+ 实测；影子状态不等于物理通断。

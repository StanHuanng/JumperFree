# 0002 JF1 冻结、JF2 并存（D3）

## 状态

已采纳；M1 冻结 JF1，JF2 留待 M3 起实现。

## 背景

现有 LED 客户端依赖 JF1 格式；新增开关事务不能改变旧客户端行为。

## 决定

永久冻结 JF1 SET/CLR/CLRALL/STATUS，使用 [jf1.vec](../../vectors/protocol/jf1.vec) 固定当前 Mock 的成功与错误应答。JF2 用独立前缀同口并存，响应前缀跟随请求，严格一请求一应答。未来 HELLO / caps 协商能力；收到旧 JF1 ERR 或超时后降级 LED-only，并明确提示。

## 后果

Python Mock、C 单测与 jf_sim 共用向量，防止实现漂移。新增命令进入 JF2，不能改写 JF1 验收值。兼容性目前只经软件验证，未经硬件验证。

# 0007 固件 LL 为主、HAL 限于 port（D1）

## 状态

已采纳；固件核心从 M4 开始，F103 port 从 M6 开始。

## 背景

固件需要控制体积、审计 GPIO 时序，同时让核心与驱动可在宿主机运行。

## 决定

F103 以 LL + CMSIS 为主，厂商 HAL 只允许出现在 `fw/port/`，不得进入 `fw/core/` 或 `fw/drivers/`。核心与驱动经项目自有 `fw/hal/` 接口访问硬件，port 提供 F103 或 sim 实现；固件负责校验、执行和影子，不做路由。

## 后果

同一 C 核心可供单测与 jf_sim 使用，底层硬件替换集中在 port。引脚、DAT/STB/RST 时序、UART 与 WS2812 参数均未经硬件验证，须后续人工实测；不因接口名称而引入 ADC 预留。

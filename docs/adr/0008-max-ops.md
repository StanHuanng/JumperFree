# 0008 max_ops=256（D10）

## 状态

已采纳为初始事务上限；M1 不实现事务或拆分。

## 背景

F103C8 按 64 KB Flash / 20 KB RAM 保守预算，事务暂存需要固定容量，避免无界内存占用。

## 决定

默认 `max_ops=256`，后续通过 HELLO 的 limits 告知主机。固件使用固定容量暂存，超限拒绝；主机对超过设备上限的计划按 net 拆分，每个中间状态必须通过短接预检，不静默截断。

## 后果

限制资源占用并使软件模拟可确定性测试；拆分需要在 service 保留事务边界及失败全断处理。实际 RAM、吞吐与执行时间未经硬件验证，后续调整须同步能力协商与向量。

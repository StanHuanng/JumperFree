# JumperFree mini bench evidence (2026-11-22)

- Clip pin map: SCH v04 and PCB v04 netlists compared, 0 differences except clip
  symbol pin 2 (same net). 7 x CH446Q pins 0 errors. LED chain RGB1..RGB48 continuous.
- Matrix self-test on the empty board: 768/768 clip-chip switches, BUS isolation,
  STB, RST and short checks PASS, 0 failures (about 11 s).
- JF2 live control (board=v04 firmware): create / merge / remove nets about 110 ms
  per commit; SAFETY_SHORT and out-of-range requests refused.
- Clip to clip path (two switches in series): about 100 Ohm (multimeter).

Not measured: emergency stop SW1, signal range and bandwidth, power-up order.
